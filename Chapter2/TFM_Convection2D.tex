\section{2D Convection}~\label{secConvection2D}
This section will cover the implementation of a C++ code for the resolution of a two-dimensional transient-state convection-diffusion transport model. The model works using a configuration file that follows the same structure discussed in the previous chapter with some additional modifications implemented when implementing this section of the model. A summary of the parameters included in the file is shown in Table~\ref{tabConfigConv}. As it can be seen, the main modifications were the addition of the velocity field, separation of temporal and convective scheme parameters, and the inclusion of a Medic data section designed to control the diagnostics tool. Finally, due to the asymmetrical nature of convective transport, an additional numerical solver using the Biconjugate Gradient Stabilized Method had to be implemented to ensure convergence and stability.

\section{Model Validation}
As mentioned above, the model will be compared to the provided reference values for the Smith-Hutton problem. This problem consists of a defined velocity field in a control volume where the presence of a transport variable is introuced. The validation will consist of comparing the steady-state solution at the boundaries with reference values for this particular problem in three main scenarios that consist of changing the ratio between the density $\rho$ and the diffusive transport coefficient $\Gamma$. For this test, $\Gamma$ will remain fixed at $1$ while $\rho$ will be evaluated at $10^1$, $10^3$, and $10^6$.

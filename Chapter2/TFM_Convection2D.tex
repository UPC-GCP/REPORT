\subsection{2D Convection}~\label{secConvection2D}
This section will cover the implementation of a C++ code for the resolution of a two-dimensional transient-state convection-diffusion transport model. The model works using a configuration file that follows the same structure discussed in the previous chapter with some additional modifications implemented when implementing this section of the model. A summary of the parameters included in the file is shown in Table~\ref{tabConfigConv}. As it can be seen, the main modifications were the addition of the velocity field, separation of temporal and convective scheme parameters, and the inclusion of a Medic data section designed to control the diagnostics tool. Furthermore, due to the asymmetrical nature of convective transport, an additional numerical solver using the Biconjugate Gradient Stabilized Method had to be implemented to ensure convergence and stability. Finally, the model has fundamentally changed from having defined nodes located at the boundaries to having ghost nodes. In consecuence, a new Boundary probe type was introduced to store the values at the boundaries.

This model will be validated by solving the Smith-Hutton problem, being used both as the test case for the numerical parameter study and for the model validation. The model validation will be done by comparing the model results to reference values provided for cases with $\rho / \Gamma = 10^1, 10^3, 10^6$. The numerical parameter study will compare the number of iterations and total residue for each of these cases for two of the convective schemes implemented for the model; namely Central Difference Scheme (CDS) and Upwind Difference Scheme (UDS).

\subsubsection{Numerical Parameter Study}
The results obtained for the previously described numerical parameter study are shown in Fig.~\ref{figConvNumerical}. As shown, using CDS will result in a higher number of iterations as the ratio increases, not being able to reach convergence within the simulation constraints for the case where $\rho / \Gamma = 10^6$. Figure~\ref{figConvCDS} shows the obtained colormap on the last time-step of the simulation. As it can be seen, there is severe checkerboarding across the domain. On the other hand, UDS was able to converge for all values across the tested range. As such, model validation will only show the colormaps for UDS. These divergence is seen due to the Peclet number ($Pe$), which is a measure of dominance between Convection and Diffusion for a given transport phenomena where $Pe << 1$ means the phenomena is diffusion dominant and $Pe >> 1$ means it is convection dominant. This means that CDS has a particular limitation that can be seen in its definition in Table~\ref{tabConvSchemes}. For simulations where $Pe > 2$, the expression will have an inverted sign and break the diagonal dominance requirement for the linear solver. On the other hand, since UDS only takes values from one side, the coefficients will never see a sign inversion, making it unconditionally stable.

\subsubsection{Model Validation}
As mentioned above, the model will be compared to the provided reference values for the Smith-Hutton problem, these values were obtained using CDS but this report will compare both UDS and CDS. This problem consists of a defined velocity field in a control volume where the presence of a transport variable is introuced. The validation will consist of comparing the steady-state solution at the boundaries with reference values for this particular problem in three main scenarios that consist of changing the ratio between the density $\rho$ and the diffusive transport coefficient $\Gamma$. For this test, $\Gamma$ will remain fixed at $1$ while $\rho$ will be evaluated at $10^1$, $10^3$, and $10^6$. The results of this test cases are shown in Fig.~\ref{figConvSH}; as it can be seen the, model accurately matched the expected results at the boundaries, with a slight expected deviation for UDS. Contrary to CDS which is second-order accurate, UDS is first-order accurate, this implies certain mathematical simplifications and as such, a slight error against the exact solution. This effect is generally seen in the smoothening of sharp gradients as can be seen in these results. In addition, the obtained steady-state solutions for UDS simulations are shown in Figure~\ref{figConvUDS}.

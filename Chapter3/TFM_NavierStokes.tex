\chapter{2D Navier-Stokes Model}~\label{chapNavierStokes}

This chapter will describe the implementation of a numerical solver for 2D Navier-Stokes problems, using the Fractional Step Method and doing the temporal discretization using an Adams-Bashforth method. The Navier-Stokes equations describe the movement of fluids by describing multiple characteristics of the movement in a system of equations. The equations shown in Eq.~\ref{eqNSMass},~\ref{eqNSMomentum},~\ref{eqNSEnergy} describe the mass conservation, momentum conservation, and energy conservation respectively. As it can be seen, these equations follow the same structure behind transport equations shown in Chapter~\ref{chapIntroduction}, with the corresponding accumulation, convective, diffusive, and source terms. The model will be evaluated against reference values provided for the Lid-Driven Case problem \cite{PENDING}, which simplifies the model by removing the energy conservation evaluation. As such, the model will require only 3 equations, one for mass conservation, and the 2 geometric components of the momentum conservation.

\begin{equation}\label{eqNSMass}
    \nabla v = 0
\end{equation}

\begin{equation}\label{eqNSMomentum}
    \rho \frac{\diff v}{\diff t} + \rho (v \nabla) v = \mu \nabla^2 v - \nabla P
\end{equation}

\begin{equation}\label{eqNSEnergy}
    \rho c_P (\frac{\diff T}{\diff t} + \nabla v T) = \nabla (\lambda \nabla T) + \dot{q}_V
\end{equation}

As mentioned above, this model uses the Adams-Bashford discretization method, which relies on two previous time-steps to evaluate the next iteration. Eq.~\ref{eqAdamsBashford} shows the expression used for this discretization method, where $R$ corresponds to the convective and diffusive terms evaluated at the corresponding time-step.

\begin{equation}\label{eqAdamsBashford}
    \rho \frac{v^{n+1} - v^n}{\Delta t} = - \nabla P^{n+1} + \frac{3}{2} R(v^n) - \frac{1}{2} R(v^{n-1})
\end{equation}

\section{Fractional Step Method}
This section will explain the different modifications that were implemented in the model to solve the current test case. As mentioned above, there is a requirement to solve multiple transport variables at the same time that are mutually dependent. Since the velocity and pressure need to be computed simultaneously, the Fractional Step Method separates this process into three separate steps. The first step consists of evaluating the velocity field while ignoring the pressure field. This calculated velocity field will not be an accurate solution for the next time-step; however, it can be used to evaluate the pressure field at the next time-step. After that second step, the only remaining operation is to correct the calculated velocity field with the influence of the now known pressure field. Since this is now a coupled solver solving for multiple variables instead of solving for a single one, the configuration file will now require the relevant details and information about every variable. As such, initial values and boundary conditions now need to be specified separately for the main solver variable and for the secondary, explicitly calculated, variables. In addition, a new Field probe was introduced specifically for the velocity field. Table~\ref{tabConfigNS} describes all the configuration parameters available for the current model.
